# Google Apps Script (архив)

Каталог переведён на **Supabase** (`supabase/migrations`, хуки `useCatalog` / `useCatalogAdmin`).  
Эта папка сохранена как эталон логики листов Google; новый фронт к Apps Script не подключается.

Ранее скрипт обрабатывал **add**, **update**, **delete** для таблицы товаров.

## Старый порядок развёртывания (только для справки)

1. Откройте таблицу Google Sheets с каталогом.
2. Расширения → Apps Script.
3. Код — файл `Code.gs` из этой папки.
4. Развёртывание как «Веб-приложение», доступ «Любой».

## Структура листа

Первая строка — заголовок. Колонки:  
id, category, name, size, quantity, price, image1, image2, image3, image4, capsule, description

Имя листа: `Merch` или `Sheet1`, либо используется первый лист.

## Логика UPDATE (без дублирования)

- Для каждого размера из запроса: если в таблице уже есть строка с этим `productId` и размером — **обновляется** эта строка (название, фото, цена и т.д.), **количество плюсуется** к имеющемуся (в форме указывается «Добавить», а не итог).
- Если строки с таким размером нет — **добавляется одна новая строка** с указанным количеством.
- Строки с этим `productId`, размер которых не пришёл в запросе (размер снят в форме), **удаляются**.

Дубликаты не создаются.
