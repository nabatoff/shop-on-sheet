

## Импорт товаров из CSV

### Что будет сделано

Кнопка "Импорт" в таблице товаров. Загрузка CSV-файла (формат экспорта), превью, отправка в Google Sheets. Сверка по паре **ID + Размер**, с учетом товаров без размера (пустой размер = отдельный ключ).

### Логика сверки

- Ключ строки: `ID + Размер` (если размер пустой, ключ = просто `ID`)
- Совпадение найдено -- перезаписать все поля строки
- Совпадение не найдено -- добавить новую строку
- Строки не из файла -- остаются без изменений
- Товар без размера: колонка "Размер" пустая, одна строка на товар
- Товар с одним размером: одна строка с заполненным размером

### Формат CSV (разделитель `;`)

```text
ID;Категория;Название;Размер;Остаток;Цена;Фото 1;Фото 2;Фото 3;Фото 4;Капсула;Описание;Предзаказ
```

### Превью перед импортом

Диалог покажет:
- Количество строк в файле
- Сколько будет обновлено (совпадение ID+Размер с существующими товарами)
- Сколько будет добавлено (новые)
- Таблицу-превью первых нескольких строк

### Технические детали

#### 1. Новый файл: `src/components/admin/ImportDialog.tsx`

- Диалог (Sheet) с зоной выбора файла
- Парсинг CSV: разделитель `;`, BOM, кавычки
- Валидация колонок: ID, Название, Цена -- обязательны; Размер -- может быть пустым
- Сверка с `existingProducts` для подсчета обновлений/добавлений по ключу `id_size`
- Прогресс-бар при импорте
- Кнопка подтверждения

#### 2. Изменение: `google-apps-script/Code.gs`

Новая операция `bulkImport` в `doPost`:
- Принимает массив `rows` (каждая строка = объект с полями id, category, name, size, quantity, price, image1-4, capsule, description, preorder)
- Читает лист Merch один раз, строит индекс `{id_size: rowNumber}` (для пустого size ключ = id)
- Для каждой строки из импорта:
  - Ключ найден: перезаписать 13 колонок этой строки
  - Не найден: добавить в batch новых строк
- Batch-добавление новых строк в конец
- Логирование результата

#### 3. Изменение: `src/hooks/useGoogleSheetsAdmin.ts`

Новый метод `bulkImport(rows)`:
- POST с `operation: 'bulkImport'` и массивом строк
- Возвращает `Promise<boolean>`

#### 4. Изменение: `src/components/admin/ProductsTable.tsx`

- Кнопка "Импорт" (иконка Upload) рядом с "Экспорт"
- Пропс `onImport` или встроенный ImportDialog

#### 5. Изменение: `src/pages/Admin.tsx`

- Подключить `bulkImport` из хука
- После успешного импорта -- refetch данных
